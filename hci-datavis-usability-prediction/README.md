1. Latar Belakang dan Deskripsi Studi Kasus

Pengembangan aplikasi digital dan dashboard informasi sering kali menghadapi tantangan pada kenyamanan antarmuka pengguna (UI/UX) dan penyajian visualisasi data. Antarmuka yang rumit menyebabkan pengguna membutuhkan waktu lebih lama dan melakukan banyak kesalahan saat berinteraksi.

Proyek ini bertujuan menerapkan model Machine Learning untuk memprediksi tingkat kualitas dan kemudahan penggunaan antarmuka pengguna (Usability Status) berdasarkan indikator perilaku interaksi pengguna dan kepadatan grafik visualisasi.

2. Fitur Input Interaksi dan Visualisasi Data

Model Machine Learning mengolah 5 variabel fitur input:

1. Task Time sec: Durasi waktu yang dibutuhkan pengguna untuk menyelesaikan tugas di aplikasi (detik).
2. Click Count: Jumlah klik antarmuka yang dilakukan pengguna.
3. Error Rate Pct: Persentase kesalahan aksi yang dilakukan pengguna.
4. Chart Clutter Score: Skala kepadatan dan kejelasan visualisasi data.
5. SUS Score: Skor kuesioner evaluasi kualitatif dari pengguna (System Usability Scale).

3. Kategori Output Hasil Klasifikasi

1. High Usability (Optimal): Antarmuka efisien dan visualisasi data sangat mudah dipahami.
2. Moderate Usability (Re-visualize): Antarmuka berfungsi baik tetapi grafik visualisasi memerlukan penyederhanaan.
3. Low Usability (Redesign Needed): Antarmuka rumit dan membingungkan yang memerlukan perancangan ulang.
