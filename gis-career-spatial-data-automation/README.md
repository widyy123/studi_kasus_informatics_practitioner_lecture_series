A. Latar Belakang dan Relevansi Karir Industry

Berdasarkan pemaparan materi oleh bapak Widi Primadepa, mahasiswa Teknik Informatika memiliki nilai tambah besar di industri GIS karena menguasai logika pemrograman dan basis data[cite: 13]. Tantangan terbesar di industri saat ini adalah masih banyaknya proses pengolahan data spasial yang dilakukan secara manual.

Proyek ini bertujuan membangun pipeline otomatisasi analisis spasial menggunakan Python dan algoritma Machine Learning untuk mengklasifikasikan status prioritas pengembangan aset secara otomatis[cite: 13].

B. Fitur Input Data Spasial

Model mengolah 4 atribut spasial utama:

1. Dist to Center: Jarak lokasi aset ke pusat aktivitas kota (kilometer).
2. Buffer Zone: Radius jangkauan/cakupan area pelayanan aset (meter).
3. Density Score: Tingkat kepadatan populasi di sekitar lokasi spasial.
4. Access Rating: Nilai kemudahan aksesibilitas jaringan jalan.

C. Kategori Output Hasil Klasifikasi

1. Low Priority: Area dengan cakupan fasilitas spasial yang sudah memadai.
2. High Priority (Blankspot): Area yang membutuhkan penambahan aset/layanan baru secara mendesak.
3. Maintenance Needed: Area dengan aset spasial yang memerlukan perbaikan/pemeliharaan rutin.
